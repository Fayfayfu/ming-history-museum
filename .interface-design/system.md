# 步入大明界面设计系统：作品型人物展厅

版本：2026-08-23
状态：已实施、由专项测试约束
适用界面：人物馆抽屉中的作品现场、人物独立页中的作品展厅

## 1. 方向与适用边界

### 设计意图

- **读者**：从人物总表、事件页或人物关系跳入人物卡，希望先看懂人物，再通过作品核验其文化身份的普通成年读者。
- **任务**：完整看见作品、辨认画幅差异、理解作品与人物网络的关系，并能继续打开馆藏记录。
- **感受**：像进入低照度博物馆展厅，作品本身明亮、安静、可停留；页面不模拟电商瀑布流，也不把作品当人物履历的装饰图。

### 启用条件

只有同时满足以下条件，才使用本规范：

1. 人物的历史身份、职业生存、思想传播或关系网络，确实需要通过可视觉展陈的作品来解释；
2. 至少有两件作者归属、馆藏入口和图像权利可说明的作品；
3. 页面策展判断明确把作品作为主要证据，而不是仅用于填补版面；
4. 作品图像能在本站合法展示，并有本地可验证资产。

不满足时：

- 只有一件代表作：使用普通“作品证据”模块，不启用大型画廊；
- 只有人物画像、纪念像或后世想象图：属于画像系统，不属于作品展厅；
- 以著述、兵书、诗文或知识体系为核心：使用文本、知识结构或训练系统，不强制套用书画画廊；
- 图像许可不明：只保留文字展签和馆藏链接，不下载、不展示大图。

### 数据开关

- `feature.type: "gallery"`：作品本身就是该人物独立页的核心专题，例如唐寅。
- `creativeGallery: true`：人物已有另一种差异化专题，但作品仍是必要的第二证据轴，例如沈周、仇英、徐渭、马守真、文徵明。
- 两者都未设置：即使 `ming_creative_works.json` 有文字或作品记录，也不自动生成大型作品展厅。

## 2. 产品领域与视觉签名

### 领域词汇

手卷、立轴、册页、题跋、装裱、递藏、展签、鉴定、馆藏、观看次序。

### 色彩世界

- 墨色画布 `--ink: #151512`：让作品成为最高亮度焦点；
- 旧纸展签 `--paper: #ebe2cd`：承载解释与来源；
- 装裱褐 `--deep: #231b18`：形成作品周围的低亮度缓冲；
- 印泥暗红 `--accent: #b14332`：只用于出处、状态和重点；
- 淡朱砂 `--accent2: #e07a62`：用于焦点与可交互提示；
- 旧绢灰褐 `--muted: #827866`：承载年代、媒材和许可等元数据。

### 视觉签名

**“全幅总览 + 全屏深看”长卷观卷台**：页面只保留一张完整缩放的长卷，让读者先看见全卷构图；局部题跋、印章和笔墨统一进入全屏查看器，以4倍或8倍缩放观察。页面不重复渲染第二张长卷。

### 拒绝的默认方案

- 等宽双栏画廊 → 按画幅语义选择通栏长卷、横幅或纵轴；
- `object-fit: cover` 裁切 → 所有作品使用 `contain`，完整性高于填满容器；
- 图片墙 + 一行标题 → 使用博物馆展签层级，保留馆藏、许可、归属和解读边界；
- 所有人物统一画廊 → 只对作品承担主要证据功能的人物显式启用。

## 3. 视觉系统

### 层级

每个作品展区只有一个焦点：**作品本身**。

1. 作品图像：最大面积、最高亮度；
2. 作品标题：宋体、约 24px、较高字重；
3. 策展解读：约 13—14px、1.8—1.9 行高；
4. 年代、媒材、馆藏、许可、置信度：等宽字体 9—12px、低亮度；
5. 馆藏入口：次级描边按钮，不与作品争夺注意力。

### 深度策略

采用**边线与表面色差**，不使用大面积卡片阴影。作品区是低照度展厅，不是悬浮卡片看板。

- 页面基底：墨色；
- 作品卡：略亮的深褐表面；
- 图像框：接近黑色；
- 分隔：低透明度米白线；
- 键盘焦点：`accent2` 2px 内描边。

### 字体

- 中文标题与正文：`Songti SC / STSong / Noto Serif CJK SC`；
- 作品题诗或古典文本：`STKaiti / KaiTi`；
- 年代、许可、英文眼眉和证据状态：等宽字体。

### 间距

- 基础单位：4px；
- 作品间距：18px；
- 桌面展签内边距：24px；
- 长卷总览内边距：桌面 16px × 24px，移动端 12px × 14px；
- 作品展区最大宽度：1420px。

## 4. 画幅分类与组件规则

`ming_creative_works.json` 的每件可视作品必须声明 `display`：

### `panorama`

适用于完整数字图像宽高比通常不低于约 3.2:1，或必须沿横向次序阅读的手卷。

- 卡片占满网格：`grid-column: 1 / -1`；
- `.art-panorama-overview`：只渲染一次完整总览，`object-fit: contain`；
- 提示条左侧标明“全卷总览”，右侧明确“全屏支持4×/8×局部查看”；
- 局部查看统一交给作品查看器，不再输出 `.art-panorama-detail` 或第二张相同图片；
- 不得让长卷引发整页水平溢出。

### `landscape`

适用于横幅、横向册页或接近方形但更适合横向观看的作品。

- 常规情况下占一个网格单元；
- 两件作品且第一件为长卷时，第二件改为通栏“图像 + 展签”左右布局，消除半栏空洞；
- 图像框高度：桌面约 `clamp(330px, 42vw, 580px)`；
- 图片始终完整缩放。

### `portrait`

适用于立轴、纵向册页或高宽比明显偏纵向的作品。

- 常规情况下与另一件作品并列；
- 图像框高度：桌面约 `clamp(520px, 60vw, 760px)`；
- 作品在框内居中、完整显示，不允许为了填满宽度裁掉题跋、印章或装裱信息。

### 移动端

- 900px 以下所有作品卡切为单列；
- 620px 以下作品区左右内边距为 21px；
- 不产生页面级水平滚动；长卷局部移动只发生在全屏查看器内部；
- 标题、元数据、解读和馆藏按钮按自然文档流排列，不使用绝对定位。

### 作品查看器

所有实际展示的作品图像共用全屏查看器：

- 桌面端提供可见的“查看大图”按钮，并支持双击作品打开；
- 620px 以下或粗指针设备支持单击作品打开；
- 使用原生 `<dialog>` 建立模态层、焦点与 `Esc` 退出语义；
- 1× 状态以 `object-fit: contain` 完整展示作品，不裁切；
- 控制区直接显示 `1× / 2× / 4× / 8×` 四个倍率入口；滚轮每次调整 0.25×，范围为 1×—8×；
- 全屏作品双击在 1× 与 2× 之间切换；
- 倍率大于 1× 后可以拖动查看题跋、印章和笔墨细节；
- 点击 `1×` 恢复完整显示与居中位置；关闭按钮点击区不小于 44×44px，并提供明确的 `aria-label`；
- 查看器不替代馆藏来源链接，关闭后仍可从展签进入馆藏原页。

## 5. 内容与证据合同

每件作品至少包含：

```json
{
  "title": "作品题名，保留传、款、仿等归属等级",
  "date": "年代或保守范围",
  "medium": "材质、形制与可核尺寸",
  "display": "panorama / landscape / portrait",
  "image": "本地作品资产路径",
  "source": "具体馆藏页 HTTPS URL",
  "collection": "馆藏机构",
  "license": "图像许可或明确的展示边界",
  "confidence": "高 / 中 / 低",
  "reading": "作品能说明什么，以及不能推出什么"
}
```

新增或重新研究的作品还应尽量补齐：`imageSource`、`rightsEvidence`、`dimensions`、`attribution`。

证据规则：

- 馆藏机构使用“传”“款”“仿”“旧传”等归属时，页面必须原样保留；
- 作品公版不自动等于数字图像无条件开放，分别记录作品权利和图像许可；
- 解读必须区分作品物质事实、馆方解释和本站策展判断；
- 不以笔墨风格直接诊断心理，不把文学题材当作现实纪实，不把赠答作品当建筑测绘或私人对话记录。

## 6. 当前复用范围

- 唐寅：`feature.type: "gallery"`，作品是职业生存与文化身份的主轴；
- 沈周：`creativeGallery: true`，作品解释赠答、师承与吴门网络；
- 仇英：`creativeGallery: true`，作品解释职业画家、藏家与长卷叙事；
- 徐渭：`creativeGallery: true`，作品与题诗并置，但不得浪漫化杀妻责任；
- 马守真：`creativeGallery: true`，作品解释女性艺术劳动与归属鉴定；
- 文徵明：`creativeGallery: true`，作品解释赠答、园林记忆与地方文化权威。

本列表是当前状态，不是封闭白名单。新增人物必须先通过第 1 节的启用判断。

## 7. 验收合同

### 自动化

- `npm run verify:featured-work-person-pages`：检查显式开关、至少两件作品、必填元数据、画幅类型、HTTPS 馆藏页与本地资产；
- `npm run verify:wild-art-literati-batch1`：检查当前艺术与文人网络五人内容边界；
- `npm run verify:wild-art-literati-layout`：用桌面和移动端真实浏览器检查通栏、完整缩放、单图总览与页面溢出。
- `npm run verify:artwork-viewer`：检查可见按钮、桌面双击、移动端单击、1×—8×缩放、滚轮、拖动、标题、关闭和无页面溢出。

### 人工视觉检查

1. 缩眼测试：作品先于标题和元数据被看见；
2. 完整性测试：题跋、印章或装裱边缘没有因 `cover` 被裁掉；
3. 长卷测试：页面只出现一次完整总览，全屏4×/8×可拖动查看局部；
4. 空洞测试：两件作品的组合不留下无意义半屏空白；
5. 交换测试：把人物姓名替换后，作品选择与解读不应仍然成立；否则说明页面又退回模板化。

## 8. 实现位置
