# 人物馆连续年代长卷设计

## 1. 目标

在人物馆增加“历史长卷”默认视图，把馆内人物按其首次具有历史作用的大概年份放入一条横向延伸的明代时间轴。

长卷回答三个问题：

1. 这些人物大致在什么时候进入历史叙事；
2. 同一时期有哪些不同身份的人同时活动；
3. 人物与皇权的制度距离、人物类别和历史影响力有何差异。

长卷不是人物评价排行榜，也不是按出生年排列的族谱。现有“人物总表”继续保留，用于搜索、筛选、排序和精确比较。

## 2. 当前数据边界

- `data/ming_core.json` 当前收录 139 人。
- `data/ming_children_important.json` 当前收录 37 条重要皇室子女记录。
- 两份数据有 13 个重名重复人物，去重后当前应展示 163 个独立人物。
- 重复人物只显示一次：人物馆核心档案作为主记录，皇室子女数据只补充亲属关系，不重复生成头像。
- 后续数据增加时，长卷自动覆盖新增人物，但每名新增人物必须补齐经过人工审校的时间轴元数据。

## 3. 页面落位

目标页面：`people.html`。

人物馆顶部提供两个同级视图按钮：

- `历史长卷`：默认视图；
- `人物总表`：保留现有表格、筛选和抽屉能力。

首次进入人物馆时显示历史长卷。切换视图不改变人物数据，也不重新加载页面。

## 4. 时间口径

### 4.1 排序原则

横坐标采用“人物首次以可识别身份进入明代历史叙事的年份”，不统一使用出生年，也不统一使用人生最高光事件年。

分类口径如下：

- 皇帝：默认采用即位年，使位置对应页面所展示的帝王身份；
- 皇子女：优先采用首次公开活动、受封、参与政局或婚姻年份；若一生只有出生记录，可采用出生年；
- 后妃与内廷女性：优先采用进入宫廷、册立或首次参与政治事件的年份；
- 文臣、武官、宦官：采用首次进入仕途、军职、内廷权力结构或首次有明确公共行动的年份；
- 在野人物：采用首次有可识别作品、思想活动、社会行动或可靠记载的年份；
- 政权人物、域外人物：采用首次与明代政治、战争或外交发生明确关系的年份。

示例：

- 于谦：1421 年进入仕途，不采用 1449 年北京保卫战；
- 王守仁：1499 年进入仕途，不采用 1519 年平定宁王之乱；
- 张居正：1547 年进入仕途，不采用 1572 年出任首辅。

后续高光事件继续显示在人物抽屉或事件关系中，不改变长卷登场点。

### 4.2 年份不详

没有精确年份时禁止伪造精度：

- 能判断年代：显示“约 1430 年代”，数值定位取该年代中点；
- 只能判断前后区间：显示“约 1435—1440”，数值定位取区间中点；
- 连合理区间也无法确定：不得自动用出生年补位，构建验证应报告为待审校数据。

页面标签必须保留“约”，不能只显示用于计算位置的中点年份。

## 5. 数据结构

新增人工审校覆盖文件 `data/ming_people_timeline.json`，不把时间轴判断散落到构建脚本中。每个去重后的人物必须有且只有一条记录。

建议字段：

```json
{
  "name": "于谦",
  "source": "core",
  "timeline_year": 1421,
  "timeline_year_label": "1421",
  "timeline_year_basis": "中进士，进入仕途",
  "timeline_year_confidence": "高",
  "timeline_source_refs": ["MINGSHI_YUQIAN"],
  "timeline_role": "兵部尚书",
  "timeline_size": "featured"
}
```

字段规则：

- `name` 与 `source` 共同确定来源记录；
- `timeline_year` 只用于同比例定位；
- `timeline_year_label` 保存页面真实显示文本；
- `timeline_year_basis` 说明为何选择该年；
- `timeline_year_confidence` 只允许 `高`、`中`、`低`、`未知`；
- `timeline_source_refs` 至少引用一条现有或新增史料来源；
- `timeline_role` 是头像下方的短身份，控制在 12 个汉字以内；
- `timeline_size` 只允许 `emperor`、`featured`、`standard`。

严禁在缺少覆盖记录时由构建脚本静默回退到 `birth`、`office_start` 或评分字段。

## 6. 长卷尺寸与严格时间比例

- 横轴年份严格同比例展开，人物的 `x` 坐标只由 `timeline_year` 决定。
- 设计基准为每年约 20—24px；时间范围由全部人物最早、最晚的 `timeline_year` 动态生成，再增加两侧留白。
- 当前数据包含明朝建立前与明朝灭亡后的相关人物，长卷不得硬截为 1368—1644；1368 与 1644 作为朝代边界重点标记，但不裁掉边界外人物。
- 按当前人物范围估算，桌面长卷约 6500—7500px 宽；未来范围变化时按同一年度比例自然增减。
- 画布基础高度约 960px，可按人物密度纵向扩展到约 1400px。
- 时间轴始终位于画布纵向中线；上下区域同步扩展。
- 页面使用正常的纵向滚动；长卷容器只负责横向滚动，不增加嵌套纵向滚动条。
- 支持触控板横滑、`Shift + 滚轮`和底部可见滚动条。
- 不通过压缩年份间距解决局部拥挤，也不为了视觉均匀而移动人物到错误年份。

## 7. 泳道结构

时间轴上方从远到近依次为：

1. 后妃与内廷女性；
2. 皇子女；
3. 皇帝。

时间轴下方从近到远依次为：

1. 宦官；
2. 文臣、武官；
3. 在野人物；
4. 政权人物、域外人物。

泳道标签只显示类别名称。宦官泳道显示“宦官”，不显示“最近皇帝”。“距离皇帝较近”只通过空间位置表达，不写成价值判断或固定人身关系。

文臣和武官共享一个大泳道带，但使用不同描边颜色，并可各自增加内部纵向层。

## 8. 人物节点

每个人物节点由四部分组成：

1. 圆形头像；
2. 姓名；
3. 一行主要身份；
4. 选中后显示的登场年份与依据摘要。

头像采用人工维护的三级影响力，不读取现有加权评分：

- `emperor`：88px；所有皇帝统一使用，金黄色描边；
- `featured`：72px；用于对历史进程有显著影响的人物；
- `standard`：56px；其他人物的最低且默认尺寸。

于谦、王守仁、张居正必须为 `featured`。负面评价人物也可为 `featured`；历史影响力与功过评价不得混为一项。

类别描边色至少区分：皇帝、皇子女、后妃与内廷女性、宦官、文臣、武官、在野人物、政权人物／域外人物。不得只靠头像大小表达人物类别。

历史原像、后世绘像和 AI 想象像继续沿用人物馆现有图像标识规则。图片加载失败时显示姓名首字占位，不出现破图图标。

## 9. 密度与重叠规则

人物密集时按以下顺序处理：

1. 保持准确的年份横坐标；
2. 在所属泳道内部寻找空闲纵向层；
3. 增加该泳道高度，并同步扩展上下画布；
4. 达到高度上限后，允许相邻人物轻度重叠。

默认重叠不超过头像直径的约 20%。同年人物保持同一时间锚点，通过纵向错层和细引导线连接到准确刻度，不伪造先后顺序。

人物姓名和身份可以在未选中状态下被邻近节点局部遮挡，但头像的可点击区域必须保留。不得把头像缩小到 56px 以下。

## 10. 选中与人物档案交互

- 点击人物头像后，头像、姓名、身份和登场年份作为一个整体提升到最高层；
- 选中节点增加明显外圈高亮，并强化其与时间轴刻度的引导线；
- 选中不改变人物位置，不触发布局重排；
- 点击其他人物切换选中对象；点击长卷空白处或按 `Escape` 取消选中；
- 已选中节点提供“查看人物档案”动作，继续打开现有人物抽屉；
- 键盘焦点必须获得与点击选中等价的置顶和高亮效果。

## 11. 构建与渲染边界

- `scripts/build_ming_html.mjs` 读取核心人物、重要皇室子女和时间轴覆盖数据，去重后生成长卷数据。
- 去重优先级：人物馆核心档案高于皇室子女补充记录。
- 布局可在构建时预计算，也可在页面初始化时确定，但同一数据和视口下结果必须稳定，禁止随机位置。
- 头像使用延迟加载；首屏外人物不得阻塞人物馆基础界面显示。
- JavaScript 失败时，“人物总表”仍可进入，人物数据不能因长卷组件失败而不可访问。
- 验证脚本必须检查覆盖完整性、年份合法性、角色文本长度、尺寸枚举和重复人物。

## 12. 响应式与可访问性

- 桌面端、平板和手机均保留同一严格年份比例，不为窄屏重新压缩时间。
- 窄屏通过横向滚动查看长卷；头像尺寸不随视口缩小。
- 视图切换使用真实 `button` 和可识别的选中状态。
- 人物节点可通过键盘聚焦，并提供包含姓名、身份、登场年份和置信度的无障碍名称。
- 泳道和人物类别不能只靠颜色区分；文本标签和无障碍名称同时说明类别。
- 选中置顶不使用必要性动画，并遵循 `prefers-reduced-motion`。

## 13. 验收标准

1. 人物馆首次打开时默认显示“历史长卷”，可切换到现有“人物总表”。
2. 当前两份人物数据去重后只出现 163 个独立人物，不重复显示 13 个同时属于皇帝与皇室子女数据的人物。
3. 每个人物都有人工审校的登场年、显示标签、依据、置信度、来源、短身份和尺寸级别。
4. 横坐标严格按年份同比例生成，范围覆盖所有人物的最早与最晚登场年；1368、1644 有清晰的朝代边界标记，但边界外相关人物仍可见。
5. 于谦、王守仁、张居正分别锚定在 1421、1499、1547。
6. 模糊年份显示“约”或完整区间，不把计算中点冒充精确年份。
7. 时间轴位于画布中线，上下泳道顺序符合第 7 节。
8. 宦官泳道只显示“宦官”，不出现“最近皇帝”。
9. 所有皇帝头像为 88px 金黄色描边；关键人物为 72px；普通人物不小于 56px。
10. 人物密集时优先错层和纵向扩展，达到高度上限后重叠不超过约 20%。
11. 点击任一人物后，其头像、姓名、身份和年份整体位于最高层，且布局不跳动。
12. 选中人物仍可进入现有人物抽屉；点击空白或按 `Escape` 可取消选中。
13. 头像全部正常显示；加载失败时使用首字占位，不出现破图图标。
14. 390px、768px 和桌面视口均可横向浏览长卷，不出现嵌套纵向滚动条。
15. 关闭长卷 JavaScript 或制造长卷数据错误时，人物总表仍然可用。
16. `npm run build:museum`、`npm run build:deploy` 与 `npm run verify` 全部通过。

## 14. 明确不做

- 不按出生年自动排列全部人物；
- 不使用人物评分自动决定头像大小；
- 不使用力导向布局、随机布局或自由拖拽人物位置；
- 不把历史高光事件年统一当作登场年；
- 不在第一版加入缩略地图、年代分页、自动播放或缩放导航；
- 不用压缩年份间距或缩小头像解决拥挤；
- 不删除或弱化现有人物总表、筛选和人物抽屉。
