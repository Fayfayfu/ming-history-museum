# 人物一生故事第三批设计

日期：2026-08-13
状态：待用户确认后实施

## 范围

本批只完善人物馆已有的五位人物，不新增馆藏人物：

- 杨溥
- 夏原吉
- 蹇义
- 郑和
- 王景弘

张辅不在当前 165 人正式名单内，本批不扩充人物范围。

## 目标

将五人的人物抽屉“一生故事”从通用基础传记改为可独立阅读的专属叙事。即使读者不了解明史，也应能从人物所处环境、关键选择、行动结果和历史限制理解其一生主线。

## 内容结构

每人必须包含：

1. 一句专属主旨，不使用可替换姓名的泛化句式。
2. 一段不少于 70 字的生平主线，交代处境、行动、结果与主要争议。
3. 四至六个专属转折章节，每章含公历年份、自动生成的年号、标题、正文及叙事层级。
4. 一段“怎样理解这个人”，明确人物能力、制度位置与历史代价。
5. 一段阅读边界，不虚构对话、心理或无法核实的现场细节。
6. 至少一个可访问的史料入口，优先使用《明史》本传、实录或权威机构资料。

## 五人的叙事重心

### 杨溥

围绕建文入仕、牵连汉王府后长期下狱、获释回到中枢、“三杨”辅政和晚年首辅展开。不得把狱中读书的次数及心理变化写成可量化事实。

### 夏原吉

围绕早期财政历练、治理江南水患、主持永乐财政、反对继续北征而下狱、仁宗复职展开。必须同时呈现其财政组织能力和国家高强度动员对民力的压力。

### 蹇义

围绕洪武入仕、长期掌吏部、跨朝维持官僚选任、储位与中枢协作展开。因人物细节相对少，不以“善于识人”等传统评价补写未经核验的具体案例；解释性结论标为合理推演。

### 郑和

围绕云南出身与被俘入宫、随燕王参与靖难、七次远航的组织与外交任务、军事行动、最后一次航行与死亡争议展开。不得采用宝船夸张尺寸，不把远航简化成个人探险或单纯和平航行。

### 王景弘

围绕现有可考的永乐三年奉命通使、多次担任副使、第七次远航和郑和去世后的归航收束展开。核心问题是大型远洋工程如何依靠副使、译者、船员与分航体系运行。对其生卒、早年和接管指挥的逐日过程明确标为材料不足。

## 证据与置信度

- 事实层：可由正史本传、实录、碑刻或权威机构资料支持。
- 推演层：用于解释制度位置、组织作用和长期影响，必须使用有限定的语言。
- 不采用艺术想象层；人物抽屉不补写内心独白和现场对白。
- 人物卡既有总置信度不自动覆盖每项叙述；争议点在正文或阅读边界中单独说明。

## 史料阅读顺序

本批不从现成人物简介直接扩写，而采用“正史提出问题、同时代材料校正、异文解释差异”的顺序：

1. 先通读《明史》相关本传和纪、志，提取生平节点、评价语、异常细节与待核问题。《明史》只负责建立检索线索，不自动作为最终结论。
2. 回到对应朝次的《明实录》，核对任命、处分、出使、战争、财政措施及事件先后。特别记录《明史》删节、合并、改写或增加因果判断之处。
3. 检索本人及同时代人的奏疏、文集、碑记和序跋。区分当事人自述、同僚观察、官方文书与身后纪念文字，不把任何一种立场当作中性记录。
4. 地方经历、家世、水利和乡里活动再查地方志。地方志成书较晚或带有乡贤褒扬目的时，不能单独支撑精确对白、心理和传奇细节。
5. 涉及对朝鲜交往、使臣观察和区域秩序时，查《朝鲜王朝实录》等朝鲜史料，用于比较明廷官方叙述与域外接收者的记录。
6. 满文档案只在人物、事件与后金或清初存在直接关系时使用。本批五人活动年代早于后金档案体系，不为追求材料种类而强行引用。

## 异文记录

每位人物建立内部史料对读表，至少记录：

- 具体命题或事件；
- 各文本怎样叙述；
- 叙述时间与作者位置；
- 一致部分、冲突部分和沉默部分；
- 差异可能来自信息条件、政治立场、修史目的、体裁限制还是后世形象塑造；
- 人物卡最终采用哪一层表述及其置信度。

“为什么不一样”只在有文本结构或历史背景支持时解释；无法判定时写明未知，不替史料作者虚构动机。人物卡正文保持可读，详细对读结果进入证据入口，不把长篇考证塞进生平叙事中。
