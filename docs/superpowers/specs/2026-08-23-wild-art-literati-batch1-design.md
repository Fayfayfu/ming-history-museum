# 在野人物第一批：艺术与文人网络设计说明

## 范围

本批只升级五位现有正式人物卡：沈周、仇英、徐渭、马守真、文徵明。沿用人物馆现有独立展厅框架、史料弹窗、历史切片和作品模块，不改变公共页面布局，不新增一套五人共用的固定“一生故事”模板。

## 五条独立叙事

- 沈周：从布衣、家学、赠画与地方交游解释“职业文人网络”如何形成。重点不是“不做官”的清高标签，而是地方文化信用怎样转化为权威。
- 仇英：从工匠训练、周臣门下、藏家驻留与文人题跋解释职业画家如何进入文人艺术核心。生卒年与部分归属有争议，整体置信度标为中。
- 徐渭：从科举失败、胡宗宪幕府、精神危机、杀妻入狱到晚年创作解释艺术转向。不得以“狂人天才”浪漫化疾病与杀妻责任，不作现代医学诊断。
- 马守真：从秦淮行业环境、兰竹署名、诗书交游与作品流通解释女性艺术劳动。与王穉登的往来可写，私人爱情对话和才子佳人细节不可当作事实。
- 文徵明：从十次应试、受荐入翰林、辞归苏州到家族门人和真伪市场解释地方文化权威。1523—1526作为入京至归里的大致时段，正文保留史料口径差异。

## 页面与证据契约

- 每人必须有独立 slug、`clear-biography` 阅读模式、4—6幕可核时间线、策展判断、最终问题和来源台。
- 每幕必须包含公历时间、朝次年号、两段正文、史料依据、明确置信度、解释边界和可打开的原典或权威馆藏链接。
- 作品模块使用现有 `ming_creative_works.json`；为文徵明补一个官方馆藏作品条目。
- 官方馆藏条目确认作品、尺寸、题识和基础履历；原典或近同时代传记确认行动与关系；现代研究只承担解释，不覆盖原典证据等级。
- 野史、后世传说或浪漫化记忆若出现，必须明确写出出处及“能确认/不能确认”的边界。本批不为凑趣强行加入无可靠出处的轶闻。

## 验收

- 人物馆抽屉出现“进入某某的一生”，五个独立页面均能构建。
- 五页主题、问题和特色模块各不相同，不能出现通用占位文案。
- 徐渭页明确写出杀妻事实与责任边界；马守真页保留“传”作归属；仇英生年使用“约”或争议说明；文徵明十试与返乡年份不互相冲突。
- 所有新增来源为 HTTPS；人物页和按需加载的详情 JSON 同步生成。
- 相关单测、构建、人物按需数据验证和浏览器页面检查通过。
