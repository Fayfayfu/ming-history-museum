# 制度馆高保真重构设计

日期：2026-08-09  
状态：待用户书面审阅  
范围：`步入大明·数字历史博物馆 / 制度馆`

## 1. 目标

把当前“六列节点＋控制面板”改造成具有明确历史空间隐喻的“帝国权力舆图”。访问者第一眼应理解皇权中枢与六大制度系统的层级关系，随后再通过年份、专题和节点交互查看制度变化。

本次是视觉与交互重构，不修改已经审校通过的机构数据。继续使用29个机构节点、47条关系、4个宏观阶段、6种阅读视图、16个来源和现有人物卡关联。

## 2. 设计判断

现页面的主要问题不是配色，而是：

- 六个系统平均分栏，削弱了皇权中心与上下层级。
- 时间、专题、系统筛选同时占据首屏，形态接近数据后台。
- 右侧详情长期占据空间，关系图被压窄。
- 所有可见节点拥有接近的视觉权重，读者缺少明确入口。
- 暗色、网格、细线组合形成通用可视化风格，缺少“步入大明”的识别度。

高保真不能靠增加纹理、阴影和动效解决，必须先重构信息层级。

## 3. 视觉方向

采用“深色帝国权力舆图”。

- 主色：墨黑、焦墨、旧纸白。
- 强调色：朱砂红，只用于当前年份、选中节点和关键制度断点。
- 辅助色：黯金用于皇权中枢，石青用于行政军事，赭红用于监察司法，暗紫用于内廷厂卫，青灰用于地方治理。
- 版式来源：明代版刻边框、舆图方位感、奏疏朱批的层次；所有视觉处理属于现代解释性设计，不伪装成历史原件。
- 字体：标题使用宋体／明朝体气质的大字，正文保持可读宋体；编号和年份使用克制的等宽字体。
- 记忆点：一条从皇帝向下贯穿内阁、六部、地方的“皇权中轴”，两翼分别展开监察司法与内廷厂卫。

禁止使用霓虹发光线、玻璃拟态、卡片阴影堆叠、渐变紫色科技感和后台仪表盘式控制器。

## 4. 页面结构

### 4.1 首屏

首屏高度控制在约70—78vh，分为三层：

1. 博物馆导航。
2. 左侧展馆标题“大明如何运转”，右侧展示当前年份、阶段名称和一句阶段判断。
3. 横向历史刻度尺，从1368至1644标出四个阶段与关键制度年份。

首屏不展示完整控制面板；访问者滚动进入舆图后再操作专题和系统。

### 4.2 权力舆图

桌面端采用非对称空间构图：

- 顶部中心：皇帝。
- 中轴上层：中书省／丞相或内阁，按年份互斥显示。
- 中轴中层：六部及六部展开节点。
- 左翼：御史台／都察院、六科、三法司、大理寺。
- 右翼：司礼监、锦衣卫、东厂、西厂。
- 下层：五军都督府、卫所、地方三司、府州县、巡抚总督。

默认只突出当前视图的关键骨架。非关键节点保持可见但降低对比度，避免用户误以为节点不存在。

### 4.3 专题导航

六种阅读视图改为舆图左侧窄栏，使用问题短标题：

- 国家机器
- 奏章成令
- 谁监督官员
- 三法司与诏狱
- 谁来调兵
- 中央与地方

窄栏只负责切换视图，不重复解释。当前视图的问题与证据边界显示在舆图上方的信息带。

### 4.4 机构档案抽屉

取消常驻右栏。点击节点后，从右侧覆盖打开宽度约380—430px的“机构档案”抽屉，内容包括：

- 机构名称、系统、节点类型。
- 当前年份存续状态。
- 主要职掌。
- 证据边界和置信度。
- 关联人物卡。
- 史料入口。

抽屉打开时舆图不重排，只轻微降暗；关闭后恢复当前关系焦点。抽屉支持关闭按钮、Escape键和焦点返回。

## 5. 交互规则

### 5.1 时间切换

- 点击四个阶段跳转到阶段默认年份。
- 拖动年份刻度按年更新节点和关系。
- 1380、1403、1420、1477等关键年份带有短标签。
- 年份切换时只对发生变化的节点执行淡入、淡出和短距离位移动画。
- 中书省与丞相在1380年后隐藏；内阁自1403年起显示；东厂自1420年起显示；西厂只在数据规定的区间出现。

### 5.2 节点聚焦

- 首次进入时突出当前视图的核心节点和中轴。
- 悬停节点时只点亮与其直接相连的当前有效关系。
- 点击节点后锁定焦点并打开机构档案。
- 点击空白处或关闭抽屉解除锁定。
- 关系线标签仅在悬停、聚焦或专题视图中出现，避免默认状态文字拥挤。

### 5.3 关系表达

保留七类关系，但不依靠七种颜色区分。以线型为主、颜色为辅：

- 皇帝直辖：朱砂实线。
- 法定统属：旧纸白实线。
- 文书流转：黯金虚线。
- 监察复核：赭红短虚线。
- 特别授权：暗紫双线或加重实线。
- 军事协同：石青长虚线。
- 业务协同：青灰点划线。

箭头语义继续遵循内容基线，不把协同关系误画成法定上下级。

## 6. 移动端

移动端不显示缩小版网络图。结构改为：

1. 固定年份与阶段切换。
2. 当前专题问题。
3. 按制度层级排列的纵向章节：皇权中枢、行政文书、监察司法、内廷厂卫、军事、地方治理。
4. 每个章节展示当前有效机构卡和少量关键关系描述。
5. 点击机构使用底部全高抽屉展示档案。

移动端仍保留年份变化、专题切换、人物卡跳转和史料入口。

## 7. 动效

- 首次进入：标题、年份刻度、中轴节点依次出现，总时长不超过900ms。
- 年份切换：结构变化总时长不超过450ms。
- 节点悬停：关系线在180—240ms内强化。
- 抽屉：260—320ms进入。
- 遵守`prefers-reduced-motion`，关闭位移与路径动画，只保留即时显隐。

动效必须帮助理解制度变化，不增加循环漂浮或装饰性粒子。

## 8. 技术结构

继续由`build_ming_institutions.mjs`生成静态HTML，不增加前端框架和网络依赖。

生成器内部拆分为以下纯函数或明确模块：

- 数据准备：读取机构图和人物机构映射。
- 布局模型：为每个机构定义语义区域、桌面坐标和层级。
- HTML渲染：首屏、时间轴、专题栏、舆图、抽屉、移动端章节。
- 客户端状态：`year`、`view`、`selectedNode`、`hoveredNode`。
- 关系绘制：根据节点坐标和当前状态生成SVG路径。
- 可访问性：焦点管理、键盘关闭、ARIA状态和降动效模式。

机构存在状态、视图过滤和人物关联继续来自现有JSON，不在页面脚本中复制历史事实。

## 9. 异常与边界

- 找不到人物映射时显示“人物馆暂未建立正式任职关联”，不得隐藏整个档案区。
- 来源ID找不到对应来源时跳过该来源并在构建验证中报错。
- 某专题在某年份只剩少量有效节点时保留专题解释，不自动切回总览。
- 西厂成化年间继续显示“阶段内反复设置”，不得推导逐年开闭。
- 视口过窄时必须切换移动端结构，不允许网络图产生横向滚动。

## 10. 验收标准

### 内容与功能

- 嵌入数据仍为29个节点、47条关系、6种视图。
- 1370年显示中书省、丞相、大都督府；不显示内阁。
- 1600年显示内阁、司礼监、东厂；不显示中书省、西厂。
- 1477年西厂可打开，档案明确“阶段内反复设置”和证据边界。
- 锦衣卫档案继续链接陆炳、纪纲、蒋瓛、田尔耕、钱宁。
- 所有现有博物馆主页面继续提供制度馆入口。

### 视觉与交互

- 1440px首屏不出现后台式大块控制面板。
- 皇帝和中枢中轴在默认视图中拥有最明确的视觉权重。
- 默认状态关系标签不重叠机构名称。
- 抽屉打开时舆图尺寸和节点坐标不变化。
- 390px视口不显示桌面SVG舆图，不产生横向溢出。
- 键盘可操作阶段、专题、节点和抽屉关闭。
- 降动效模式下不执行结构位移动画。

### 验证

- `npm run build:museum`
- `npm run verify:institutions`
- `npm run verify:institution-page`
- `npm run verify`
- `npm run build:deploy`
- 浏览器检查1440×1000、1024×768、390×844三个视口。

## 11. 明确不做

- 不新增机构、关系或人物卡。
- 不制作明代全部官署表。
- 不增加3D宫殿、地图疆域或游戏化数值。
- 不伪造奏折、官印、舆图等历史文物。
- 不为了视觉效果改变关系方向或机构存续时间。
