# 郑和抽屉与独立页六阶段文案统一设计

## 目标

把郑和人物抽屉和独立页统一到同一条六阶段生平主线，解决当前三类问题：

1. 抽屉仍使用旧四幕速览，缺少年号和摘要。
2. 独立页仍使用旧四幕长文，没有采用第三批已经完成的六阶段结构。
3. `ming_storytelling.json` 与 `ming_person_pages_batch2.json` 各自维护一套郑和文案，容易继续漂移。

## 信息层级

### 人物抽屉：六段简明速览

抽屉只承担“看完即可理解郑和一生轮廓”的任务。每段固定包含：

- 公元年份；
- 明代年号；
- 一个直接、具体的阶段标题；
- 一句事实摘要。

六个阶段为：

1. 约1371—1402：身份被战争与宫廷改写；
2. 1405—1407：首次组织跨洋船队；
3. 1407—1415：外交、交换与武力并行；
4. 1416—1424：持续组织远航与港口网络；
5. 1424—1431：永乐帝死后转任南京守备；
6. 1431—1433及身后：第七次远航及卒地争议。

抽屉不展开史料争议、长篇解释和引文，只保留进入独立页的明确入口。

## 独立页：六段完整叙述

独立页采用与抽屉完全一致的六阶段顺序，但每段展开为完整叙述：

- 交代事件背景和行动缘由；
- 说明郑和在船队、宫廷和港口网络中的具体位置；
- 区分可证事实、合理解释和仍有争议的内容；
- 不虚构郑和的对话、心理和现场动作；
- 继续保留现有“移动的国家”解释装置。

独立页不直接复制第三批短故事正文，而是以六阶段主线为骨架，把现有独立页中更充分的事实细节重新分配到对应阶段。

## 双纪年规则

抽屉与独立页六个阶段同时展示公元年份和年号：

| 公元年份 | 年号显示 |
| --- | --- |
| 约1371—1402 | 明 · 洪武四年至建文四年 |
| 1405—1407 | 明 · 永乐三年至五年 |
| 1407—1415 | 明 · 永乐五年至十三年 |
| 1416—1424 | 明 · 永乐十四年至二十二年 |
| 1424—1431 | 明 · 永乐二十二年至宣德六年 |
| 1431—1433及身后 | 明 · 宣德六年至八年及身后 |

第一阶段的出生年仍属约数，页面不把1371年写成无争议的精确出生年份。

## 史料与证据边界

继续使用并显露以下来源：

- 《明史》卷304；
- 《明太宗实录》相关记载；
- 刘家港天妃宫石刻《通番事迹记》；
- 长乐《天妃之神灵应记》；
- 故宫博物院有关陶瓷与下西洋性质的研究；
- 郑和航海图及图像来源。

其中：

- 航次、奉使身份和部分军事行动可作高置信度陈述；
- 早年被俘、宫刑过程和具体靖难战功材料不足，不补写细节；
- 卒年、卒地与遗体归葬保留争议提示；
- 对船队动机、地方社会感受和国家成本的解释明确标为解释层，不写成唯一结论。

## 数据与渲染规则

`data/ming_person_pages_batch2.json` 作为郑和抽屉与独立页的页面内容来源：

- `scenes` 改为六段；
- 每段补齐 `reignYears` 和 `preview`；
- 独立页继续读取同一组 `scenes` 的完整正文；
- 设置清晰传记阅读模式，使非皇帝人物也可在抽屉显示年号和一句摘要。

`data/ming_storytelling.json` 保留第三批内容验证用途，但郑和页面不再从其中生成另一套可见正文。后续若修改郑和主线，应同步校验两者的阶段数量、日期和标题含义，禁止再次出现四幕与六阶段并存。

## 验收标准

1. 郑和抽屉显示六个阶段，而不是四个。
2. 每个阶段同时显示公元年份和年号。
3. 每个阶段有一句简明摘要。
4. 独立页显示相同顺序的六个完整章节。
5. 刘家港碑、长乐碑和《明史》入口仍可访问。
6. 抽屉与独立页在桌面和390px移动端均无横向溢出。
7. 全站人物故事、年号和部署包验证继续通过。

## 不在本次范围

- 不重写其他人物独立页；
- 不扩展到《明实录》之外的大规模多源研究；
- 不调整郑和专题展的整体视觉设计；
- 不推送远端或上线。
