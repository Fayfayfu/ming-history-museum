# 人物馆扩展至1662与南明分支设计

## 决策

全馆叙事范围统一为 1368—1662。

- 1644：北京明廷覆亡，是不可抹平的主断点。
- 1662：永历帝遇害，作为南明终局和事件馆、人物馆历史长卷的终点。
- 人物寿命不受 1662 限制。1662 年后的经历可以留在独立人物页的生平概述中，但不进入本馆的主时间轴、事件馆或关系网主范围。

目标不是把南明附在“明亡”之后，也不是创建一条伪造的连续帝系；目标是让读者看见 1644—1662 年多政权竞争、合法性争夺、征服与抵抗的历史结构。

## 非目标

- 不将弘光、隆武、永历追加为北京明廷的第 17—19 位皇帝。
- 不把“南明”或“跨朝活动”设为人物身份分类；文臣、武官、宗室、在野人物等既有分类仍保留。
- 不复制人物。一个人物在搜索、名录、关系网和人物馆中始终只有一个正式实体与一个独立页。
- 不将清初活动继续计作北京明廷活动，也不因“忠烈”“降清”等标签预先赋予人物正负评价。
- 本轮不立即扩写所有南明人物卡；先完成可承载内容的时间、筛选、帝系与数据结构。

## 信息架构

### 帝系

人物馆保留 `北京明廷帝系 · 16帝（1368—1644）` 作为主线。

主线末端新增一个并列分支：`南明延续政权 · 1644—1662`。

第一层显示三位主要君主：

1. 弘光帝朱由崧（1644—1645）
2. 隆武帝朱聿键（1645—1646）
3. 永历帝朱由榔（1646—1662）

鲁王监国及其他竞争性政权不挤入单线帝序；以分支说明或政权网络展示其并行性。帝系文案明确：16 帝统计只指北京明廷，南明是覆亡后的延续政权与合法性竞争，而非单一顺序继位。

### 人物筛选

现有身份和领域筛选之外，增加“历史时段”筛选：

- 北京明廷（1368—1644）
- 南明诸政权（1644—1662）
- 明清交替（人物在 1644 后以清朝、大顺、遗民或其他位置继续活动）

“历史时段”是可多选的经历筛选，不是人物分类。筛选结果仍只显示同一个人物实体；结果卡展示命中的身份沿革阶段及其年份。

卡片采用低干扰边标：北京明廷为墨绿、南明为赭金、跨朝阶段为灰褐。颜色只表达政权阶段，不表达忠奸、贡献或人物评分。

### 身份沿革

人物数据新增可多值的 `politicalPhases`（名称可在实施时按现有数据命名习惯调整）。每段包括：

```json
{
  "regime": "明|弘光|隆武|永历|鲁王监国|大顺|清|遗民",
  "start": 1642,
  "end": 1650,
  "role": "该阶段的制度身份或社会位置",
  "confidence": "高|中|低|未知",
  "sourceIds": ["来源登记键"]
}
```

示例只用于数据行为说明，不替代事实核验：

- 洪承畴：明朝军事行政官员 → 清朝大学士、经略。
- 傅山：明末士人 → 清初明遗民、书画家与医家。
- 吴三桂：明朝辽东总兵 → 清朝平西王。

人物页将此呈现为“身份沿革”，而不是两张履历卡。每段均需来源、年份范围与置信度。角色发生变化时，时间轴中的同一节点轨迹跨越 1644 断点后改变边标和文字，不复制肖像或姓名。

## 历史长卷与关系网

### 历史长卷

人物馆的历史长卷由 1368 延长至 1662，保持单一比例尺。视觉与叙事上设置两个断点：

- 1644：北京失陷、北京明廷覆亡。
- 1662：南明终局。

1644—1662 不称为“明朝继续正常存在”，而标为“多政权竞争与南明延续”。该段同时容纳弘光、隆武、永历、鲁王监国、大顺余部、清军征服、海上力量与地方行动，避免单一忠烈叙事。

跨朝人物只显示一次。其轨迹可从 1644 前延至 1644 后，后段显示新的政权归属。若人物仅在清初继续从事思想、艺术、医学等活动，使用“清初活动”或“明遗民”准确标记，不能称为明廷活动。

### 关系网

关系网年份范围由 1368—1644 延展为 1368—1662；不截断在 1644。关系边和节点沿用一个人物实体，新增按时间筛选或视觉区分，以表达同一人物在不同政权阶段的关系变化。1662 后的历史不进入主关系网，避免范围重新无限外延。

## 数据与构建

1. 建立政权枚举与展示顺序，避免每个页面自行书写“南明”“弘光”“清初”等不一致名称。
2. 为既有跨朝人物补 `politicalPhases`，先覆盖人物馆中已有且与 1644—1662 事件直接相连的人物。
3. 新增南明人物时，同时写入人物主表、政权阶段、来源、人物页、事件关联和关系数据；不能只增加一张前端卡。
4. 扩展时间轴、帝系和关系网的年份常量与范围文案；保留无 JavaScript 的完整人物名录与按需详情加载。
5. 事件馆现有 1644—1662 事件作为锚点复用；人物页跳转必须定位同名正式人物，不能跳到模糊搜索结果。

## 内容批次

范围结构稳定后，内容按以下次序推进：

1. 崇祯危机：升级既有崇祯朝核心人物，解释财政、辽东、军政和民变如何共同压缩修复空间。
2. 1644—1645 留都选择：弘光、马士英、史可法及江北军镇关键人物。
3. 1645—1646 多中心抵抗：隆武、黄道周、郑芝龙、鲁王监国相关人物。
4. 1646—1662 永历与西南：永历、瞿式耜、李定国、孙可望等。
5. 海上与征服：郑成功、郑氏政权、吴三桂、多尔衮及相互关系。

每张卡遵循“历史困境 → 可考行动 → 政权条件 → 后果 → 证据边界”。野史可作为接受史或争议材料出现，必须注明出处、层级与不可证实部分。

## 验收

- 人物馆明确标注 1368—1662；首页、事件馆、人物馆、关系网的范围文案不再矛盾。
- 北京明廷帝系仍为 16 帝；南明三位主要君主出现在独立分支并可跳转。
- 同一人物只在名录、搜索和关系网出现一次；身份沿革可显示多个阶段。
- “历史时段”筛选可准确找出南明与明清交替人物，且不破坏原有身份、领域、拼音、繁体、别名搜索。
- 长卷保持 1644 与 1662 两个断点，并能显示跨朝人物的后段身份。
- 无 JavaScript 人物名录、按需详情、静态回退、浏览器桌面/移动端、数据审校和全站回归均通过。

## 风险与处理

- 政权归属可能重叠或变动：允许同一时期多条阶段记录，靠来源和置信度解释，不能强行唯一化。
- 南明合法性与人物评价争议大：展示多政权并置和行动后果，不用颜色或卡片排序预先裁定。
- 清初活动容易无限扩展到清史：以 1662 作为全馆主范围截止；之后仅保留人物页必要的生平收束。
- 既有构建脚本中存在 1644 年硬编码：先建立范围常量和回归测试，再改页面，避免页面之间终点不一致。
