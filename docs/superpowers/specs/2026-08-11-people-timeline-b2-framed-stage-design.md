# 人物馆历史长卷 B2「框中暗卷」设计

日期：2026-08-11
状态：已确认方案 1，待用户审阅书面规格

## 目标

在完整保留现有 B 版的前提下，新增独立的 `people-timeline-b2.html`。B2 要解决 B 版深浅配色边界不清的问题：人物馆页面继续使用原版米白色，只有历史长卷画布成为一件边界明确的深色展品。

判断标准不是“页面只能有一种颜色”，而是用户能一眼理解：米白区域属于人物馆的信息与操作界面，深色区域属于正在观看的历史长卷。

## 页面隔离

- 现有 `people-timeline-b.html` 原样保留，不修改其视觉结果。
- A、C、current 与正式 `people.html` 不变。
- B2 使用独立 URL、独立版本键和独立 CSS 作用域，不通过 query 参数覆盖 B。
- B2 与其他版本共享人物数据、时间布局、头像加载、拖拽、选择、抽屉、双击和无 JavaScript 回退。

## 颜色边界

### 米白页面域

以下区域与正式人物馆保持同一套米白配色：

- 全站导航；
- 人物馆标题、导语、范围说明与统计卡；
- “历史长卷 / 人物总表”切换按钮；
- 人物总表、筛选器和状态文字；
- 人物档案抽屉及遮罩层中的纸面内容。

B2 不允许把深色文字反向继承到这些区域，也不允许切换到人物总表后残留暗色页面背景。

### 深色长卷域

只有 `#peopleTimelineView` 所在的长卷展框使用深色：

- 展框外缘使用克制的铜褐色细框和内阴影，明确它是一件嵌入页面的展品；
- 画布延续 B 版低亮度观卷氛围，但不再把 `body`、标题区或统计区变暗；
- 时间轴、泳道标签、人物姓名和身份改用满足可读性的浅色；
- 人物头像、发光选中环和分类描边保持原有语义颜色；
- 左右卷轴端部与边缘遮罩保留，但必须完全位于展框内部，不覆盖页面级控件。

不增加木纹背景、粒子、音效、持续动画或额外的大面积装饰。

## 结构与交互

- `.people-timeline` 继续承担版本模块与标签页结构；深色视觉只作用于内部长卷视窗和它的装裱层。
- “历史长卷”视图显示深色展框；切换到“人物总表”后，深色展框隐藏，页面保持完整米白。
- 横向滚动条、鼠标拖拽、触控板和键盘滚动继续可用。
- 单击人物保持选中与聚焦；双击头像打开人物档案抽屉。
- 打开、关闭抽屉不得改变长卷的横向位置；抽屉继续使用正式人物馆的米白纸面配色。
- 移动端继续使用既有独立人物档案路由，不新增 B2 专属人物数据或页面。

## 尺寸与响应式

- 桌面端长卷模块整体高度不得超过 1000px。
- 1440、768、390 三种宽度下，页面主体宽度不得超过视口；只有长卷视窗允许横向滚动。
- 展框、卷轴端部和遮罩不得裁掉任何可见头像、姓名、身份、年份标签或滚动条。
- 不通过纵向缩放人物画布来满足高度约束，避免圆形头像变成椭圆。

## 无障碍与降级

- 展框是命名明确的时间长卷区域，不创建重复地标。
- 深色画布中的普通文字与背景对比度至少 4.5:1；大字号文字至少 3:1。
- 焦点环在深色画布和米白页面上都清晰可见。
- 遮罩、卷轴端部与装裱层不接收指针事件，也不进入键盘顺序。
- JavaScript 禁用时沿用人物总表回退，不显示无法操作的长卷。
- B2 专属 CSS 失效时退化为共享的明亮长卷，人物内容仍可阅读。

## 验收与测试

实现必须遵循测试先行，并至少覆盖：

1. 构建产物新增且仅新增独立 `people-timeline-b2.html`，正式 `people.html` 未切换版本。
2. B2 的 `body`、标题、统计、标签页、人物总表和抽屉与 current 的关键计算颜色一致。
3. B2 的长卷视窗为深色、边界明确，且页面外层仍为米白；不得出现 B 的全页暗色舞台标记。
4. 深色长卷文字对比度达到 4.5:1，遮罩与卷轴端部 `pointer-events:none`。
5. 163 人、年份比例、泳道、影响力尺寸及头像资源与共享长卷一致。
6. 整体高度不超过 1000px；1440、768、390 三种视口无页面级横向溢出。
7. 非零横向位置上的拖拽、单击、双击、抽屉开关和关闭后位置恢复正常。
8. 无 JavaScript 时显示人物总表；头像失败占位、键盘焦点和移动端人物路由不退化。
9. 对 B 版做视觉契约回归，确保新增 B2 没有改变现有 B。

## 明确不做

- 不把 B2 接入正式人物馆，也不替用户做最终选版。
- 不修改现有 B、A、C 或 current 的视觉设计。
- 不修改人物数据、史实、年份、分类、评分、影响力或图片资源。
- 不重做人物总表、人物抽屉和全站导航。
- 不加入展开仪式；B2 是稳定的观卷状态，不复制 C 的动画。
