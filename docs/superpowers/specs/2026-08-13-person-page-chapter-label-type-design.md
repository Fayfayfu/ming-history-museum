# 独立人物页章节辅助文字字号调整设计

## 目标

提高独立人物页章节区域中两类辅助文字的可读性，同时保持章节标题、公元年份、年龄和正文的现有视觉层级。

## 调整范围

- `.chapter-reign`：由11px调整为13px，用于左侧年号。
- `.chapter-copy .eyebrow`：调整为14px，用于右侧“第一幕 · ……”章节眉题。
- 公元年份、年龄、章节大标题、正文及其他页面元素不变。

该规则作用于所有使用同一独立人物页生成器的页面，不为郑和创建单独样式，避免同类页面字号不一致。

## 响应式要求

- 1440px桌面视口不得产生横向溢出。
- 390px移动视口不得产生横向溢出。
- 年号和章节眉题允许按现有容器自然换行，但不得相互遮挡或挤压章节正文。

## 验收标准

1. 郑和独立页六章的年号计算字号均为13px。
2. 郑和独立页六章的章节眉题计算字号均为14px。
3. 桌面端与390px移动端页面宽度不超过视口。
4. 独立人物页和全站部署包验证继续通过。
5. 不推送、不上线。
