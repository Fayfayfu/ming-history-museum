# 皇帝“统治与制度”模块设计

## 范围

本轮只修改朱元璋人物抽屉。其他皇帝、大臣、武将和宦官保持现状。

## 信息架构

- 基本信息表只回答：这个人是谁、何时生卒、来自哪里、何时在位、皇室关系如何。
- 大臣等人物继续使用“关联机构”，用于说明任职、掌权或正式职衔关系。
- 皇帝不使用“关联机构”，因为皇帝名义上关联大量国家机构，简单罗列缺乏区分度。
- 皇帝使用“统治与制度”，用于说明其创设、废除、恢复或重组了什么。

## 朱元璋页面

- 从基本信息表中移除“关键制度改造”。
- 在人物速览之后、生平事迹与史学评价之前，增加“统治与制度”正文模块。
- 保留四项内容：废除中书省与丞相、六部直接奏事、军事中枢重组、监察与侦缉重组和创设。
- 四项内容按纵向正文阅读，不使用基本信息表格或标签矩阵。
- 明确六部是吏、户、礼、兵、刑、工六个并列机构的合称。

## 验收

- 基本信息表内不存在“关键制度改造”或四项制度卡片。
- 基本信息表之后存在且仅存在一个“统治与制度”模块。
- 模块位于人物速览之后、生平评价之前，包含四项完整说明。
- 朱棣及其他人物的既有“关联机构”展示不受影响。
- 桌面与移动端无水平溢出。
