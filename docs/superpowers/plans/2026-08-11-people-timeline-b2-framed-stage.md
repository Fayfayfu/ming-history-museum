# 人物馆历史长卷 B2「框中暗卷」Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增独立的 `people-timeline-b2.html`，在原版米白人物馆页面内嵌一幅边界明确的深色历史长卷，同时完整保留现有 B、A、C、current 和正式 `people.html`。

**Architecture:** 沿用 `people_timeline_variants.mjs` 的共享变体注册、CSS 注入和拖拽控制器，只为 `b2` 增加独立版本键、展框语义标记与局部样式。B2 不复制人物数据或布局逻辑；浏览器验证将 B2 与 current 的页面、表格、抽屉颜色逐项比较，并单独验证深色长卷的对比度、几何、交互与降级。

**Tech Stack:** Node.js ESM、静态 HTML/CSS/JavaScript、Node test runner、Playwright、现有 Ming museum 构建脚本。

## Global Constraints

- 现有 `people-timeline-b.html` 原样保留，不修改其视觉结果。
- A、C、current 与正式 `people.html` 不变。
- B2 使用独立 URL、版本键和 CSS 作用域，不通过 query 参数覆盖 B。
- B2 页面、标题、统计、标签页、人物总表和抽屉保持正式人物馆的米白配色。
- 只有 `#peopleTimelineView` 及内部装裱层使用深色；不得出现 B 的全页暗色舞台。
- 共享 163 人数据、年份比例、泳道、头像、影响力尺寸、拖拽、选择、双击、抽屉和无 JavaScript 回退。
- 长卷模块整体高度不得超过 1000px；1440、768、390 三种宽度下仅长卷视窗允许横向滚动。
- 不得使用 `scaleY` 或其他非等比缩放压缩人物画布；圆形头像保持正圆。
- 深色画布普通文字对比度至少 4.5:1；大字号文字至少 3:1。
- 遮罩、卷轴端部和装裱层必须 `pointer-events:none` 且不进入键盘顺序。
- 不修改人物史实、年份、分类、评分、影响力或图片资源。
- 不加入展开仪式、声音、粒子或持续动画。
- 严格遵循 RED → GREEN；没有先观察到预期失败，不得写生产代码。

- [ ] **Step 4: 完成 B2 浏览器验证函数**

新增 `verifyB2(page, currentPage)`，复用 `captureTableStyles`、`captureDrawerStyles`、`sameStyle` 和对比度函数：

```js
async function verifyB2(page, currentPage) {
  await page.goto(`file://${path.join(root, 'people-timeline-b2.html')}`, { waitUntil: 'domcontentloaded' });
  await page.waitForSelector('[data-scroll-stage="framed"] [data-scroll-drag-surface]');
  const pagePalette = await capturePageStyles(page);
  const currentTimeline = await capturePageStyles(currentPage);
  const stagePalette = await captureB2StageStyles(page);
  const geometry = await captureB2Geometry(page);
  return { pagePalette, currentTimeline, stagePalette, geometry };
}
```
