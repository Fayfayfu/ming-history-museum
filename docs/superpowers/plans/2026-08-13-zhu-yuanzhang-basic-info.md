# 朱元璋人物卡基本信息重排实施计划

**范围：** 只修改朱元璋人物抽屉；其他人物沿用现有基本信息结构。

## 目标

- 将“子女数量”和“帝系关系”合并为完整的“皇室关系”。
- 将只显示锦衣卫的“关联机构”替换为“关键制度改造”。
- 使用“帝位来源”描述开国皇帝，避免误用“入继”。
- 将评分模块从基本信息表格中分离，降低信息层级混乱。

## 数据与呈现

1. 在朱元璋人物页数据中加入 `basicInfo`，作为仅供该人物使用的展示资料。
2. “皇室关系”分为家庭出身、子女、帝位与继承三栏。
3. “关键制度改造”列出：废中书省与丞相、六部直接奏事、军事中枢重组、监察与侦缉重组和创设。
4. 明确六部是六个并列机构的合称，不把它画成位于六部之上的单一机构。
5. 补充低干扰的证据边界说明：本馆重要子嗣数量不是完整价值排序，开国前祖系称号多为建国后的追尊。

## 验证

- 浏览器测试锁定三栏皇室关系、四项制度改造、无“入继”、无旧“关联机构／子女数量”标签。
- 验证评分区位于基本信息表之外。
- 验证朱棣仍使用旧结构，防止改动扩散到其他人物。
- 验证桌面端与移动端无水平溢出。
