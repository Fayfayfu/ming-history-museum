# 步入大明 · 网页字体

本站自托管的 WOFF2 均为站内实际用字子集，避免加载三套完整中文字体。子集使用新的内部字体名称，不沿用上游保留名称：

- `Ming Museum Serif`：衍生自 Source Han Serif SC 2.003R，SIL Open Font License 1.1。
- `Ming Museum Sans`：衍生自 Source Han Sans SC 2.005R，SIL Open Font License 1.1。
- `Ming Museum Inscription`：衍生自 LXGW WenKai 1.522，SIL Open Font License 1.1。

许可分别见 `OFL-Source-Han-Serif.txt`、`OFL-Source-Han-Sans.txt` 和 `OFL-LXGW-WenKai.txt`。子集只用于网站嵌入，不单独出售。
