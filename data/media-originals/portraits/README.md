# 人物画像原图

这里统一保存人物馆、事件馆和专题展使用的人物画像原图，不直接作为网页发布目录。

## 目录规则

- `batch-N/`：与人物画像生产批次一致；文件名采用 `编号_姓名_图像性质_原图.png`。
- `imagined/`：早期未纳入编号批次、但已被网站引用的 AI 想象像。
- 同一人物存在不同构图时，不覆盖：保留所在批次或用途差异。例如冯保同时有 `imagined/` 专题展版本与 `batch-7/` 人物馆版本。
- 未采用版本使用 `候选02`、`候选03` 等后缀，不写成“原图”或“采用”。
- 所有 AI 生成人物图继续按网站既有规则标识为“AI想象像”，不冒充传世画像。
