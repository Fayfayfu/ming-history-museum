# Imagegen 原始生成图归档

这里集中保存本项目在 Codex 图片生成目录中产生的原始图片，避免项目依赖用户缓存目录。

## 目录规则

- 每个子目录使用 Codex 任务 ID 命名。
- 人物原图统一进入 `data/media-originals/portraits/`，场景原图统一进入 `data/media-originals/scenes/`；任务目录只保留清单和溯源信息。
- 文件采用内容语义命名；`manifest.json` 的 `originalFile` 永久保留最初的 `exec-UUID`，因此重命名不会切断来源链。
- 每个任务目录内的 `manifest.json` 记录文件大小、SHA-256、内容分类、采用状态，以及项目内是否存在完全相同的已采用文件。
- `adopted: false` 只表示没有找到同哈希的项目采用文件，不表示图片应当删除；它可能是未采用版本、候选稿或尚未接入的原图。
- 每个已整理任务目录提供 `CATALOG.md`，方便按人物、专题和场景位查找与调用。
